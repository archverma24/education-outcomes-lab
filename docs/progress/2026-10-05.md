# Day 9 — 2026-10-05

## Added

The dashboard now shows a missing-value count for every column, a total missing-cell count, and a bar chart when any column has missing values. It explicitly reports when the current dataset has none. The view appears before validation stops model analysis, so a missing grade can be inspected without training on invalid data.

## Why

The real public UCI course data has no missing grades, so a synthetic missing-value case is needed to verify the error view and chart behavior.

## Files and checks

Updated the dashboard, README, public-data CI check, roadmap, and Day 8 progress log. GitHub Actions runs unit tests and the public-data dashboard check, then temporarily writes a synthetic 20-row derivative of the public UCI data with one missing G1 value. Streamlit AppTest checks the missing count, failed schema status, readable G1 error, and absence of model metrics; the original public file is restored in CI. The final PR head's checks are the validation record; no local checkout or local test run was used.

## Publication

PR #10: https://github.com/archverma24/education-outcomes-lab/pull/10. Day 8's verified PR #9 merge is reconciled in the roadmap and progress log.

## Limitation and learning

Missingness is descriptive; it does not explain why a value is absent or justify filling it in. The synthetic fixture is for testing and is not a real student-data claim.
