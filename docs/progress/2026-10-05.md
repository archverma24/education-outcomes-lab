# Day 9 — 2026-10-05

## Added

The dashboard now shows a missing-value count for every column, a total missing-cell count, and a bar chart when any column has missing values. It explicitly reports when the current dataset has none. The view appears before validation stops model analysis, so a missing grade can be inspected without training on invalid data.

## Why

The real public UCI course data has no missing grades, so a synthetic missing-value case is needed to verify the error view and chart behavior.

## Limitation and learning

Missingness is descriptive; it does not explain why a value is absent or justify filling it in. The synthetic fixture is for testing and is not a real student-data claim.
