# Day 8 — 2026-10-04

## Added

The final-grade chart now has an "All schools" or school-specific selector and shows the number of course records in its current view. A reusable helper counts grades in the selected rows without changing the source data. The model metrics remain based on the full dataset; unchanged model results are cached across chart-filter reruns.

## Why

A reader can inspect how the historical grade distribution varies by school while keeping the model comparison separate from a chart-only filter.

## Files and checks

Updated the dashboard, README, public-data dashboard CI check, roadmap, and Day 7 progress log; added an exploration helper and fixture tests. GitHub Actions runs the unit suite and verifies that selecting GP changes the chart count to the GP row total while the full-dataset model metric remains unchanged. The final PR head's checks are the validation record; no local checkout or local test run was used.

## Publication

PR #9: https://github.com/archverma24/education-outcomes-lab/pull/9. Day 7's verified PR #8 merge is reconciled in the roadmap and progress log.

## Limitation and learning

These are descriptive counts from one historical public course dataset. Filtering the chart does not estimate a new school-specific model or support a school ranking; matching chart and subset counts is a separate check from model evaluation.
