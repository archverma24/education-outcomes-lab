# Day 10 — 2026-10-06

## Added

The dashboard shows an alphabetical table of school-level final-grade mean, median, and course-record count. The view describes historical Portuguese-course records without ranking schools or claiming a school caused a grade difference.

## Why

A mean alone hides how many records support it. Showing sample sizes and medians makes the comparison easier to interpret without presenting it as a school-performance judgment.

## Files and checks

Added a reusable aggregate helper, fixture tests, a dashboard table, a public UCI AppTest assertion in GitHub Actions, and README guidance. CI checks the real public course data against independently calculated group counts, means, and medians, and checks that sample counts sum to 649. GitHub Actions is the validation record; no local checkout or local test run was used.

## Publication

PR #11 proposes this change. Merge only after latest-head unit and public-data dashboard checks pass; verify the merged PR and resulting `main` commit.

## Limitation and learning

These are descriptive statistics from one historical dataset. They do not identify why groups differ or support decisions about current students. Day 9's verified PR #10 merge is reconciled in this PR.
