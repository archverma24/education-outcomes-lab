# Day 17 — 2026-10-13

## Added

A reusable split configuration now accepts a random seed and test fraction, checks invalid settings, and returns reproducible, disjoint train/holdout row positions. The model uses those positions and keeps its original default of seed 42 and a 20% holdout.

## Why

This delayed Day 15 prerequisite makes future validation and split manifests reproducible while preserving the historical baseline. Rows are selected by position so duplicate DataFrame index labels cannot accidentally duplicate membership.
