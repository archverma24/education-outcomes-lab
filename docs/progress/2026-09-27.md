# Day 1 — 2026-09-27

## Added

Created Education Outcomes Lab: validated UCI data ingestion, a reproducible late-year grade prediction benchmark, a Streamlit dashboard, and automated pipeline tests. Added source attribution, proposal, roadmap and daily development procedure.

## Results

- Public Portuguese-course dataset: 649 records; 519 train / 130 test; random seed 42.
- Linear regression MAE: 0.732755 grade points; RMSE: 1.168901.
- Training-mean baseline MAE: 2.394605; RMSE: 3.172590.
- Three pipeline test methods passed, including six invalid-schema cases, repeatability, feature selection and safe archive handling.
- G1 and G2 are the only predictors; G3 is the target.
- Streamlit AppTest smoke check passed with three expected metrics and no app exceptions.

These are preliminary historical-data results from one split. This is not an early-warning model or a system validated for current students.

## Learning

Compare a model with a simple baseline on held-out data. Earlier-grade prediction may look accurate because second-period grades are close in time to final grades; that does not demonstrate useful early intervention.
