# Day 22 — 2026-10-18

## Added

The training-only validation report now includes one out-of-fold linear-model prediction and residual for every outer-training row from the first repeat. The dashboard plots predicted grade against actual minus predicted grade with labeled axes and a zero reference line.

## Why

This completes the delayed Day 19 residual-diagnostics prerequisite. A single repeat gives each training record exactly one diagnostic point, while the reserved test partition remains excluded.

## Files and checks

Updated the validation module, dashboard, fixture tests, public UCI CI assertions, README, roadmap, and progress logs. GitHub Actions runs the unit suite and checks the public-data residual positions, values, and dashboard on the PR head. No local checkout or local test run was used.

## Publication

This change is proposed in the Day 22 PR. Merge only after latest-head checks pass; verify the merged PR and resulting `main` commit.

## Limitation and learning

Residual patterns are descriptive for historical Portuguese-course records. They do not establish causal effects or performance for new populations; the Day 1 holdout was already viewed. The October 17 run produced no PR and is recorded separately.
