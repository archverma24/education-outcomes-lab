# Day 3 — 2026-09-29

## Added

Added optional verification against a trusted SHA-256 checksum. The CLI can check either an existing dataset or bytes being downloaded. A rejected download stops before replacing the current file; the expected checksum is not changed.

## Checks

The PR runs the repository's GitHub Actions pipeline test suite. Its latest-head status is the validation record for this GitHub-only change; no local checkout or test run was used.

## Learning

A hash only verifies integrity when its expected value comes from a trusted source. The project accepts the expected value explicitly and refuses changed bytes rather than silently updating it.
