# Day 18 — 2026-10-14

## Added

The CLI now exports a train/holdout split manifest with the source CSV hash, split settings, counts, and zero-based row positions. It does not export student records or claim the positions identify students.

## Why

The delayed Day 16 split-manifest task is a prerequisite for training-only repeated validation. Binding positions to the source hash prevents treating them as portable row identifiers after the dataset changes.
