# Day 5 — 2026-10-01

## Added

Added a non-destructive exact duplicate-row audit to the reusable dataset profile and benchmark JSON report. It counts each row that repeats an earlier row across every source column, including repeated missing values. The report explains that matching values do not prove the records belong to the same student; no source rows are deleted.

## Why

Repeated values can be useful to investigate, but automatically removing records could discard observations from different students with identical recorded attributes.

## Checks

Fixture tests cover repeated whole rows, rows that differ in one column, repeated missing values, and preserving the original data. GitHub Actions' unit tests and public UCI check passed on PR #6's final head commit (a252473fa16d8df943b9971a01abf7637e9059ca). The public-data check compared the CLI audit count with the source CSV. No local checkout or local test run was used.

## Publication

PR #6 was squash-merged into main: https://github.com/archverma24/education-outcomes-lab/pull/6. The merge was verified on 2026-10-01 Pacific time. Day 4's verified PR #5 merge is reconciled in the roadmap and progress log.

## Limitation

Exact value matches are a descriptive data-quality signal, not a student identity test. This audit cannot establish whether any two records represent the same person.
