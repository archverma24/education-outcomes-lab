# Day 7 — 2026-10-03

## Added

The dashboard now shows a data-quality section computed from the currently loaded public dataset: rows checked, grade-schema status, exact duplicate-row count, and an expandable aggregate validation/profile report. If grade data fails validation, the panel shows the issues and stops model analysis. Matching rows are not deleted or treated as confirmed duplicate students.

## Why

A visible quality panel gives viewers context for the model results and exposes data problems before charts or scores can be misread.

## Limitation and learning

The panel describes one historical public dataset; passing the grade schema does not prove source accuracy, student identity, causal relationships, or model suitability for current students. Recomputing quality metrics from the loaded file avoids presenting stale cached figures.
