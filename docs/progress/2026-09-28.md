# Day 2 — 2026-09-28

## Added

Added a versioned provenance manifest for the public UCI Portuguese-course CSV. It records the citation, source URL, CC BY 4.0 license, course, file name, UTC retrieval time when downloaded in the current run, and SHA-256 of the exact file bytes. The CLI writes it to `reports/provenance.json` and includes the same metadata in the benchmark report.

## Learning

A file hash is more useful when it is attached to clear source, license, course, and retrieval metadata. When the CLI uses an existing local dataset instead of downloading it, the retrieval time stays unknown rather than being guessed.
